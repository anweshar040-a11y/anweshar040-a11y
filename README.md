## Featured Project

### Statistical Arbitrage Trading Strategy

An end-to-end quantitative trading research project implementing a cointegration-based pairs trading strategy on Indian equities.

**Key components**

* Cointegration and stationarity testing using Engle-Granger and ADF.
* OLS and Kalman Filter hedge ratio estimation.
* Mean-reversion signal generation using rolling Z-scores.
* Custom backtesting engine with transaction costs and trade logging.
* Risk analysis with Sharpe Ratio, Sortino Ratio, CAGR, Calmar Ratio, and Drawdown.
* Walk-forward validation and parameter optimization.
* Interactive Streamlit dashboard for portfolio analytics.
